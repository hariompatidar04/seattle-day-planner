# 🌍 World Time Zone Clock

A beautiful, interactive digital clock application that displays the current time across multiple time zones around the world.

## Features

✨ **Key Highlights:**
- 🕐 **Dual Display** - Both digital and analog clock faces for each timezone
- 🌍 **10 Default Timezones** - Pre-loaded with major cities worldwide
- ➕ **Customizable** - Add or remove any of 33+ timezones globally
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- 📱 **Fully Responsive** - Perfect on mobile, tablet, and desktop
- 🔄 **Real-time Updates** - Updates every second automatically
- 📊 **Detailed Info** - Shows date, hour, and minute for each timezone

## Available Timezones

The app includes support for 33+ major timezones including:
- Americas: Los Angeles, Chicago, New York, Mexico City, Toronto, Vancouver
- Europe: London, Paris, Berlin, Rome, Istanbul, Moscow
- Asia: Tokyo, Shanghai, Hong Kong, Dubai, Bangkok, Kolkata, Manila, Seoul, Singapore
- Africa: Cairo, Lagos, Johannesburg, Nairobi
- Oceania: Sydney, Melbourne, Auckland, Fiji

## How to Use

1. **View Default Timezones** - The page loads with 10 major timezones automatically
2. **Add a Timezone** - Click the "+ Add Timezone" button to open the timezone selector
3. **Select & Add** - Choose from the dropdown and add it to your view
4. **Remove Timezone** - Click the "Remove" button on any clock card to delete it

## Technical Details

- **Pure HTML/CSS/JavaScript** - No frameworks or external dependencies required
- **Intl API** - Uses native JavaScript Internationalization API for accurate timezone handling
- **CSS Animations** - Smooth transitions and real-time hand movements on analog clocks
- **Responsive Grid** - Auto-adjusting layout for any screen size
